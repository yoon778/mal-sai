<h1 align="center">말사이</h1>

<p align="center">
  대화 사이를 읽는 AI 썸 채팅 연습
</p>

소개팅 이후처럼 답장이 막막한 순간을 실제 메신저와 가까운 환경에서 연습하는 AI 대화 게임입니다. 상대의 성향과 앞선 대화를 읽고 5번 답장한 뒤, 잘한 점과 고칠 점을 구체적으로 복기합니다.

## 핵심 경험

- **상황형 연습** — 소개팅 직후, 연락처만 받은 사이 등 5개 시나리오
- **실전형 메신저** — 이모티콘, 읽음 상태, 가상 답장 시간과 대화 흐름
- **단계별 도움** — 막막할 때만 확인하는 힌트와 답장 방향
- **행동 중심 피드백** — 점수, 잘한 점, 개선점, 더 나은 답장 예시
- **즉시 재도전** — 같은 상황을 다시 풀며 바뀐 결과 비교

## 플레이 흐름

1. 관계와 상황 선택
2. 이전 대화에서 상대 성향 파악
3. AI 상대와 5번 티키타카
4. 대화 전체 평가와 답장별 피드백 확인
5. 같은 상황 재도전

## AI 설계

| 역할 | 하는 일 |
| --- | --- |
| 대화 상대 | 설정된 성향과 관계 단계에 맞춰 자연스럽게 반응 |
| 코치 | 정답을 대신 쓰기보다 다음 답장의 방향을 힌트로 제공 |
| 평가자 | 관심 표현, 질문과 자기표현의 균형, 맥락 연결, 부담감 등을 종합 평가 |

평가 품질을 확인할 수 있도록 5개 상황과 강함·약함·혼합 답장을 조합한 기준 사례 30개를 관리합니다. 실제 AI가 꺼진 상태에서는 준비된 반응만 사용하며 AI 점수로 표시하지 않습니다.

## 실행

Node.js 22 이상 필요. 별도 패키지 설치 없음

```bash
npm start
```

브라우저에서 <http://localhost:3000> 접속

```bash
npm test
npm run eval:validate
```

실제 AI 평가는 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`, `AI_ENABLED=true`를 설정한 뒤 실행합니다

```bash
npm run smoke:ai -- --limit 1
npm run eval:ai -- --limit 3
npm run realism:ai
```

`smoke:ai`는 대표 상황을 실제로 완주하고 대화·힌트·평가의 응답 시간과 토큰·추정 비용을 `.data/smoke-live-*.json`에 기록합니다. 한 판부터 확인한 뒤 최대 세 판까지 실행합니다.

## 현재 상태

- 대화 게임 프로토타입 완성
- 핵심 동작 테스트 9개
- AI 평가 기준 사례 30개
- 로컬 API 비용 상한과 사용량 기록 적용
- 실제 AI 대화·힌트·평가 3상황 완주 검증
- 실제 AI 상대 10회·답장 50개 현실감 회귀 검증
