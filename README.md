<h1 align="center">말사이</h1>

<p align="center">
  대화 사이를 읽는 AI 썸 채팅 연습
</p>

소개팅 이후처럼 답장이 막막한 순간을 실제 메신저와 가까운 환경에서 연습하는 AI 대화 게임입니다. 상대의 성향과 앞선 대화를 읽고 최대 5번 답장한 뒤, 잘한 점과 고칠 점을 구체적으로 복기합니다. 한 번 이상 답장하면 자연스럽게 마무리하고 관찰된 대화만 평가받을 수도 있습니다.

## 핵심 경험

- **상황형 연습** — 소개팅 직후, 연락처만 받은 사이 등 13개 시나리오
- **실전형 메신저** — 이모티콘, 읽음 상태, 가상 답장 시간과 대화 흐름
- **자연스러운 말풍선** — 짧은 반응과 두세 줄 답장을 섞어 1~3개 말풍선으로 전송
- **단계별 도움** — 막막할 때만 확인하는 힌트와 답장 방향
- **주제 이어가기** — 말이 끊겼을 때 꺼낼 소재, 연결 문장, 다음 흐름 연습
- **답하고 이어가기** — 상대가 던진 질문에 답한 뒤 관련 이야기를 보탰는지 복기
- **늦은 답장 연습** — 관심이 낮은 가상 상대와 답장 대기, 30분·2시간 가상 시간 이동
- **인물별 말투** — 여성·남성 가상 인물, 존댓말·반말, 적극성과 농담 성향 조합
- **행동 중심 피드백** — 점수, 잘한 점, 개선점, 더 나은 답장 예시
- **즉시 재도전** — 같은 상황을 다시 풀며 바뀐 결과 비교
- **한 문장 복습** — 복기한 행동을 새로운 상황에서 적용하고 점수 없이 피드백 확인
- **품질 제보** — 동의한 대화 맥락과 모델·프롬프트 버전으로 어색한 답장과 평가 제보

## 플레이 흐름

1. 관계와 상황 선택
2. 이전 대화에서 상대 성향 파악
3. AI 상대와 최대 5번 티키타카 또는 조기 마무리
4. 대화 전체 평가와 답장별 피드백 확인
5. 같은 상황 재도전 또는 새로운 상황에서 한 문장 복습

## AI 설계

대화 상대와 힌트·평가는 **GPT-5.4 mini** 사용
상황 13개, 가상 선연락, 연락 약속 수습, 스토리 답장, 지난 이야기 연결, 농담·오해 수습을 연습할 수 있습니다
명확한 표기 오류 두 유형만 별도로 안내하며 채팅식 표현과 가벼운 오타는 넘어갑니다
최신 적용 범위와 검증은 [상황 기믹·코칭 업데이트](./docs/conversation-gimmicks.md), 이전 실험은 [디자인 및 AI 업데이트](./docs/design-and-ai-update.md) 참고
복기는 원문·개선 이유·다른 답장 예시·이어가기 방법과 해당 차례 재도전을 제공

| 역할 | 하는 일 |
| --- | --- |
| 대화 상대 | 설정된 성향과 관계 단계에 맞춰 자연스럽게 반응 |
| 코치 | 정답을 대신 쓰기보다 다음 답장의 방향을 힌트로 제공 |
| 평가자 | 관심 표현, 질문과 자기표현의 균형, 맥락 연결, 부담감 등을 종합 평가 |

평가 품질을 확인할 수 있도록 5개 상황과 강함·약함·혼합 답장을 조합한 기준 사례 30개를 관리합니다. 실제 AI가 꺼진 상태에서는 준비된 반응만 사용하며 AI 점수로 표시하지 않습니다.

## 실행

웹 서비스 배포 설정과 서버 생성 순서: [Render로 웹 서비스 열기](./docs/web-release.md)

Node.js 24 이상 필요. 웹 서버는 Node 기본 모듈만 사용하며 토스 패키지 빌드는 `npm ci`로 도구를 설치합니다

```bash
npm start
```

브라우저에서 <http://localhost:3000> 접속

디자인 초안 3종: [간결한 도구형 / 대화 퀘스트 / 메신저 집중형](http://localhost:3000/designs#b)
대화·복기 화면과 모바일 배치를 비교할 수 있으며 시안에서는 API를 호출하지 않음
초기화·힌트·주제·전송 버튼의 배치와 강조 방식 비교: [디자인 근거와 적용 범위](./docs/control-designs-2026-09-09.md)

```bash
npm test
npm run eval:validate
```

실제 AI 평가는 `.env.example`을 `.env`로 복사하고 `OPENAI_API_KEY`, `AI_ENABLED=true`를 설정한 뒤 실행합니다

```bash
npm run smoke:ai -- --limit 1
npm run eval:ai -- --limit 3
npm run realism:ai
npm run reliability:ai
npm run feedback:summary -- --participants 5
```

`smoke:ai`는 대표 상황을 실제로 완주하고 대화·힌트·평가의 응답 시간과 토큰·추정 비용을 `.data/smoke-live-*.json`에 기록합니다. 한 판부터 확인한 뒤 최대 세 판까지 실행합니다.

사용자 테스트는 [진행 가이드](./docs/user-test-guide.md)에 따라 3~5명에게 요청합니다. 대화·진행 상황·평가와 별도의 설문·신고를 `.data/practice.sqlite`에 암호화해 저장합니다. 설문 레코드에는 대화 전문을 복사하지 않습니다. 이전 JSONL 의견 파일은 자동으로 이관하지 않으며 기존 DB가 없을 때 집계 도구로 읽을 수 있습니다.

## 현재 상태

- 대화 게임 프로토타입 완성
- 핵심 동작 자동 테스트
- AI 평가 기준 사례 30개
- 로컬 API 비용 상한과 사용량 기록 적용
- 실제 AI 대화·힌트·평가 3상황 완주 검증
- GPT-5.4 mini 대화 상대와 답장별 복기 카드 연결
- 서로 다른 레이아웃의 디자인 초안 3종·화면 크기 3종 확인
- 기존 AI 평가·현실감 실험 이력은 구현 상태 문서에 기록 — 새 모델의 자연스러움에 대한 인간 평가는 미완료
- 사용자 테스트 설문·로컬 집계 도구 준비
