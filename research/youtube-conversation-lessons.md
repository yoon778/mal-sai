## 확인 범위

- 사용자 참고 영상은 YouTube 공개 페이지의 제목·채널·설명·챕터 확인
- 추가 영상 5개는 YouTube 공식 oEmbed로 제목·채널 확인, Lilys 공개 자동전사로 내용 확인
- 원영상 전체 시청이나 원음과 전사의 대조는 수행하지 않음
- 시간 표기는 참고 영상은 작성자 챕터, 추가 영상은 자동전사의 구간 안내이며 발언 정확성을 보증하지 않음

공통 주제를 제품 언어로 요약하면 **상대가 준 말을 받아서, 필요한 만큼 보태고, 다음에 말할 여지를 만드는 연습**
이는 직접 만든 요약이며 모든 차례에 ‘공감 + 내 경험 + 질문’을 채우라는 고정 공식이 아님

## 서로 다르거나 그대로 채점하면 안 되는 조언

- 빠른 답장이 호감을 높인다는 V2의 주장은 공통 법칙으로 채택하지 않음
- V0의 ‘칼답 유형’ 챕터는 세부 발화 미확인이라 V2와 정반대라고 단정하지 않음
- 상대의 짧은 반응만으로 사람에 대한 무관심을 단정하지 않음 — 피곤함·주제·습관도 가능
- V5의 불편한 질문에 대한 경계는 일반적인 질문에 답하기와 구분 — 거절도 좋은 대응일 수 있음
- 성별에 따른 호감 공식, 거절을 시험으로 간주하는 조언, 일부러 애매하게 만들어 추격하게 하는 조언은 공통 교육 규칙에서 제외
- 웃음·이모지 개수, 말풍선 2개, 질문 1개, 몇 분 대기 같은 숫자를 정답으로 만들지 않음

질문 연구에서도 단순한 개수 공식은 주의가 필요함
[Huang 등 2017 원연구](https://www.hbs.edu/ris/Publication%20Files/Huang%20et%20al%202017_6945bc5e-3b3e-4c0a-addd-254c9e603c60.pdf)는 질문과 반응성·호감의 관계를 보고하지만, [2019 재분석](https://pmc.ncbi.nlm.nih.gov/articles/PMC6857721/)은 관계 단위의 효과 해석에 이견을 제시함
이는 한국어 썸 카톡 평가표 자체가 검증됐다는 뜻은 아님

## 현재 AI에 접목하는 최소 방법

현재 코드에는 직전 상대 말과 사용자 답을 묶는 `replyOpportunities`, 원문에 연결된 `moments`, `reason`, `alternative`, `nextStep` 구조가 이미 있음
부족한 것은 출처·적용 조건·예외가 연결된 교육 자료

1. 원칙별 자료 카드 작성 — 원칙 ID, 적용 상황, 관찰 행동, 예외, 창작 예시, 출처와 확인 범위
2. 현재 상황에 관련된 카드 2~3개만 평가 AI에 전달 — 첫 버전은 상황 태그로 선택하면 충분
3. 복기 결과에 원칙 ID 연결 — 서버에서 확인된 출처와 설명을 붙임
4. 대화 상대 AI에는 인물의 성향과 반응 예시를, 평가 AI에는 교육 원칙을 제공
5. 같은 대화에 가능한 좋은 답변 여러 개와 반례를 만들어 실제 출력 검증

강좌의 설명체를 상대 AI에 그대로 넣으면 매 답장을 가르치려는 말투가 될 수 있음
현실적인 상대가 항상 대화를 살려주도록 만들지 않고, 종료 뒤 코치가 놓친 기회를 설명하는 구성이 목적에 적합

OpenAI도 [공식 최적화 가이드](https://developers.openai.com/api/docs/guides/model-optimization)에서 평가 기준을 세우고 관련 맥락·지시·예시를 제공한 뒤 대표 입력으로 검증하는 과정을 안내
이번 단계는 파인튜닝 없이 가능하며, 자료량이 적으면 벡터 데이터베이스도 불필요
유튜브 URL을 API에 전달하는 것만으로 모델이 영구 학습되는 방식은 아님

## 창작 연습 예시

상대: 오늘 면접 끝났어 결과 기다리려니까 떨린다
사용자: 저녁 뭐 먹었어?

- 관찰: 상대가 꺼낸 면접 결과에 대한 걱정을 받지 않고 다른 소재로 이동
- 다른 답장: 면접 보느라 고생했네 결과는 언제 나온대?
- 이후: 결과 발표 시점을 말하면 그 답에 반응하고, 상대가 다른 이야기로 환기하고 싶은지 흐름을 살핌
- 예외: 상대가 앞서 면접 얘기를 그만하고 싶다고 했다면 저녁 이야기로 바꾸는 것이 적절할 수 있음
- 금지: 사용자가 말한 적 없는 ‘나도 지난주에 면접 봤는데’를 대안에 추가

## B형에서 만들기 좋은 미션

1. 질문받았을 때 답하고 이어가기
2. 면접처럼 질문만 하지 않기
3. 짧은 반응 뒤 이어갈 단서 찾기
4. 끊긴 대화에서 지난 소재 다시 꺼내기
5. 상대가 피곤할 때 자연스럽게 끝내기

추천 첫 범위: 위 5미션에 원칙 카드 10개 정도를 수동 검수하고, 각 카드에 좋은 예·아쉬운 예·예외를 한 세트씩 작성
분량은 개발 범위 제안이며 학습 효과가 검증된 숫자는 아님
기존 평가의 ‘질문과 자기표현 둘 다 있어야 높은 점수’ 문구는 좋은 경청에도 형식을 강요할 수 있어 우선 검토 대상
