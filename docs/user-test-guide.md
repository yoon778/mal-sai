# 말사이 사용자 테스트 가이드

## 대상과 목표

- 20~30대 3~5명
- 소개팅 뒤 카톡이나 썸 대화 경험자가 있으면 우선
- 목표: 완주율 80% 이상, 피드백 유용성 평균 4점 이상, 진행 막힘 0건

## 참여자 안내

> 실제 카카오톡 대화나 개인정보를 입력하지 말고 가상의 답장을 작성해 주세요. 정답을 맞히려 하지 말고 평소처럼 진행해 주세요.

1. 첫 화면에서 원하는 상황을 고르거나 랜덤 상황 선택
2. 이전 대화를 읽고 상대 성향 추측
3. 답장 5회 진행. 막막할 때만 힌트 사용
4. 결과와 답장별 근거 확인. 원하는 차례 한 번 재시도
5. 결과 아래 `1분 사용자 테스트` 제출

## 진행자 관찰 항목

- 시작부터 결과까지 완주 여부
- 설명 없이 멈춘 화면과 행동
- 이해하지 못한 피드백 문장
- 힌트를 쓴 차례와 이유
- 재시도 기능 발견 여부

진행 중 사용법을 먼저 알려주지 않음. 완전히 막힌 경우에만 화면과 원인을 기록한 뒤 도움

## 결과 확인

피드백은 `.data/feedback.jsonl`에 저장됨. 대화 내용은 저장하지 않음

```bash
npm run feedback:summary -- --participants 5
```

자유 의견보다 반복된 진행 막힘을 먼저 수정함. 수정 뒤 같은 흐름을 직접 한 번 완주함
