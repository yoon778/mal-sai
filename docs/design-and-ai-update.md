# 디자인 초안과 AI 업데이트

확인일 2026-09-07

## 세 가지 시안

`npm start` 후 [디자인 스튜디오](http://localhost:3000/designs)에서 A/B/C와 대화·복기 화면 전환 가능
예시 전송·다시 쓰기·재도전 동작만 제공하는 디자인 초안이며 AI 호출 없음
실제 플레이 중인 대화를 바꾸거나 저장하지 않음

| 시안 | 구성 | 적합한 방향 |
| --- | --- | --- |
| A 연습 노트 · 추천 | 종이색·세이지, 여백이 있는 비대칭 배치, 장면별 복기 노트 | 시험 부담을 줄이고 배운 내용을 돌아보기 |
| B 대화 퀘스트 | 코랄·노랑, 미션 티켓, 단계 표시, 다시 도전하는 버튼 | 짧은 연습을 게임처럼 반복하기 |
| C 포커스 룸 | 어두운 배경, 내비게이션 레일, 대화와 복기 나란히 보기 | 실제 메신저 같은 몰입과 데스크톱 사용 |

추천 조합은 A의 기본 화면과 B의 가벼운 진행 표시
선택 전 실제 앱에는 복기 카드만 연결했고 전체 디자인은 시안 페이지에서 비교하도록 구성

참고한 디자인 원칙과 우리 앱에 적용한 해석:

- [Headspace 디자인 인터뷰](https://developer.apple.com/news/?id=fkfnhq8u): 따뜻한 인상, 명료한 활동 이름, 단순한 진입 동선 → A의 부담 낮은 분위기에 참고
- [Duolingo Practice Tab](https://blog.duolingo.com/guide-to-duolingo-practice-hub/): 필요한 기술과 실수를 다시 연습하는 흐름 → B의 미션·복기·재도전 구조에 참고
- [Linear UI 재설계](https://linear.app/now/how-we-redesigned-the-linear-ui): 환경·외형·정보 위계를 나누어 실제 화면으로 검증 → C의 대화 중심 작업 공간에 참고

원본 로고·일러스트·화면을 복제하지 않고 말사이에 맞게 새로 구성한 시안

## AI 변경

대화 상대 기본 모델: `gpt-5.4-mini-2026-03-17`
힌트·주제 도움·평가 기본 모델: `gpt-4.1-mini-2025-04-14` 유지
`.env`의 `AI_REPLY_MODEL`, `AI_COACH_MODEL`로 역할별 선택 가능
지원 목록에 없는 모델은 비용을 계산할 수 없으므로 호출 전 중단

| 모델 | 입력 / 캐시 입력 / 출력, 100만 토큰당 USD | 용도 |
| --- | --- | --- |
| GPT-4.1 mini | 0.40 / 0.10 / 1.60 | 기존 기준, 코칭 유지 |
| GPT-4.1 | 2.00 / 0.50 / 8.00 | 비교 후보 |
| GPT-5.4 mini | 0.75 / 0.075 / 4.50 | 대화 기본값, reasoning none |

공식 요금·지원 기능: [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [GPT-4.1](https://developers.openai.com/api/docs/models/gpt-4.1), [GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)

모델별로 요청 전 예산 예약과 실제 토큰 정산을 모두 변경하고 사용량 로그에 모델명을 추가
기존 $3 로컬 상한 유지

자연스러움을 위한 구현 변경:

1. 설명용 JSON 안의 대화 기록을 실제 user/assistant 메시지 역할로 전달
2. 특정 차례의 말풍선 개수·웃음 표현을 강제로 채우던 규칙 제거
3. 직접 작성한 한국어 예시로 한 줄 반응·나눠 보내기·자연스러운 마무리 제시
4. 환자·일정의 주체는 고정하고 존댓말 예문이 반말에 끼어드는 상황 규칙 수정
5. 라이브 답장은 정규식으로 존댓말을 반말로 바꾸지 않음 — 모델이 생성한 문장을 검증하고 온점만 별도 처리
6. 성별 대신 합의한 말높임·관심·적극성·농담 성향을 전달

역할·지시·예시·맥락을 나누는 방식은 [OpenAI 프롬프트 가이드](https://developers.openai.com/api/docs/guides/prompt-engineering)를 참고
이번 변경은 추론 시 프롬프트·맥락 개선이며 유튜브 학습이나 모델 파인튜닝을 수행한 것은 아님

## 복기 카드

실제 사용자 답장 1~3장면을 선택해 직전 상대 말 → 내가 보낸 답장 → 이유 → 다른 답장 한 가지 → 이후 이어가기 → 해당 차례 재도전 순서로 표시
관찰된 사용자 ID만 허용하고 없는 ID·빈 예시·잘못된 길이는 서버에서 거절
같은 답장에 중복 생성된 카드는 검증 후 하나만 표시
다른 답장은 정답으로 표시하지 않으며 사용자의 취향·일정·경험을 만들어 넣지 않도록 지시

## 비교와 한계

합성 상황 6개씩 기존 프롬프트와 세 모델을 비교
기존 mini의 일부 결과에서 아픈 주체 뒤바뀜·사용자 문장 반복·상담 문체가 관찰됐고, GPT-5.4 mini가 1차 동일 상황에서 주체를 유지했으며 GPT-4.1보다 비용이 낮아 우선 선택
첫 비교의 일부 입력은 예시와 유사했으므로 공정한 독립 벤치마크 점수로 제시하지 않음
이후 예시 소재를 바꾸고 실제 메시지 역할 전달 후 다시 확인

최종 구성의 3상황 완주(답장 5회 + 힌트 1회 + 평가 1회): $0.011836 / $0.011379 / $0.011471, 평균 약 $0.0116
짧은 테스트의 실측이며 캐시·대화 길이·재시도·추가 도움·세금에 따라 달라짐
추가로 반말 취소·낮은 관심·설정 공개 요구를 포함한 3상황 15답장과 복기 완주 확인

한계: 같은 약속·배려를 재확인하거나 과하게 친절한 답장이 남음
형식 검증 통과와 사람 같은 말투는 별개이며 소규모 합성 테스트만으로 자연스러움을 입증하지 못함
평가 모델 후보도 시험했지만 채점 품질 향상의 충분한 근거가 없어 기존 모델 유지
사용자가 어색한 실제 출력에 표시를 남기고, 동의를 받은 익명 예시를 모아 비교 평가하는 단계가 다음 과제
