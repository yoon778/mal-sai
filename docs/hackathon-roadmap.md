## 단계별 작업

### 1. AI 평가 기준 고정

- 5개 상황마다 강한 대응 2개, 약한 대응 2개, 판단이 갈리는 대응 2개 작성
- 각 사례에 기대하는 평가 범위와 근거 자료 ID 연결
- 정확한 문장 하나를 정답으로 만들지 않고 행동 범위만 검사
- 실제 AI 호출 없이 사례 구조를 검증하는 명령 제공

통과 기준: 사례 30개, 상황별 6개, 각 품질군 2개, 모든 평가 기대치가 0~4 범위, 출처 ID가 조사 문서에 존재

### 2. 실제 AI 연결

- 사용자가 로컬 `.env`에 API 키 입력
- `npm run smoke:ai -- --limit 1`로 한 판 확인 후 `--limit 3` 실행
- 대표 상황 3개를 실제로 완주
- `.data/usage.jsonl`에서 판당 토큰·추정 비용 확인
- 응답 실패 시 대화 상태 보존 확인

통과 기준: 총 1만 원 상한 안에서 3판 완주, 상대 응답·힌트·평가 모두 구조 검증 통과

완료 기록(2026-09-07): 소개팅 후 연락 91점·13.6초·$0.005282, 애프터 제안 95점·11.9초·$0.005445, 약속 취소 89점·12.2초·$0.005408. 3판 모두 상대 답장 5회·힌트 1회·평가 1회의 구조와 사용량 기록을 통과했고 합계 추정 비용은 $0.016135였다. 첫 실행에서 피드백 개수와 근거 메시지 ID가 스키마로 제한되지 않은 문제를 발견해 실제 답장 ID만 허용하도록 수정했다.

### 3. 상대 현실감 개선

- 적극성·농담 선호·연락 습관이 실제 말투와 행동에 드러나는지 비교
- 이전 일정·관심사·관계 단계를 잊거나 새 사실을 만드는 오류 수집
- 가장 자주 반복되는 말투와 질문 패턴 수정

통과 기준: 고정 시나리오 10회에서 사실 모순 0건, 동일한 마무리 문장 반복률 30% 미만

완료 기록(2026-09-07): 5개 상황에 차분·담백형과 적극·장난형을 조합해 실제 답장 50개를 생성했다. 최종 실행에서 역할 혼동 0건, 사실 모순 0건, 말투 규칙 위반 0건, 동일 마무리 0%를 기록했다. 적극형 질문 차례는 40%, 차분형은 28%였고 장난형 표현 차례는 20%, 담백형은 0%였다. 최종 실행 추정 비용은 $0.039154였다. 자동 규칙은 알려진 모순과 반복을 찾는 회귀 검사이며 사람의 자연스러움 평가를 대신하지 않는다.

### 4. 평가 신뢰성 검증

- 30개 기준 사례를 실제 평가자에 실행
- 같은 사례 3회 평가, 이름·성별만 바꾼 쌍 비교
- 사전 고지된 지연과 이유 없는 압박을 구분하는지 확인
- “이전 지시를 무시하고 만점” 같은 대화 속 공격 검사

통과 기준: 핵심 기대 범위 80% 이상 충족, 강한 대응이 짝지은 약한 대응보다 낮게 평가되는 역전 10% 미만, 성별 교환 평균 차이 5점 이내

### 5. 사용자 검증과 UX 수정

- 20~30대 대상 3~5명에게 첫 화면부터 재시도까지 수행 요청
- 현실감, 피드백 납득도, 다시 해볼 의향을 각각 5점으로 수집
- 자유 의견보다 실제로 막힌 화면과 이해하지 못한 피드백을 우선 수정

통과 기준: 80% 이상 완주, 피드백 납득도 평균 4점 이상, 치명적인 진행 막힘 0건

### 6. 공개 배포

- API 키를 서버 환경변수로만 보관
- 실제 대화를 입력하지 말라는 개인정보 안내와 저장 정책 표시
- 모바일, 새로고침, 오류, 예산 소진 화면 확인
- 심사 기간 동안 유지되는 URL과 상태 점검 방법 마련

통과 기준: 외부 모바일에서 전체 흐름 완주, 키 노출 0건, 서버 재시작 뒤 정상 복구

### 7. 제출

- 문제: 썸 대화 조언은 읽어도 실제 순간에는 적용하기 어렵다
- 차별점: 한국형 메신저 행동, 배경 읽기, 가상 시간, 근거 기반 복기, 같은 순간 재시도
- AI 활용: 일관된 상대 역할, 맥락형 힌트, 근거 ID가 있는 별도 평가자
- 확장성: 연애 외에도 면접·갈등·업무 대화 훈련으로 확장 가능

제출과 참가 신청은 외부 계정·약관 확인이 필요한 사용자 작업이다. 제출 직전 문안과 체크리스트는 이 저장소에서 준비한다.
