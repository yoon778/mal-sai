# 말사이 토스 출시 보안 점검 · 2026-09-09

코드와 시험 패키지 점검 완료, 실제 서비스 배포·심사 제출 전 단계

## 수정한 항목

| 항목 | 수정과 검증 |
| --- | --- |
| 무작위 식별키로 토스 검증 API 반복 호출 | 요청원 IP당 30회/분 구간·서버 전체 300회/분 구간, 초과 시 외부 검증 호출 전 차단 |
| 인증 제한 우회용 IP 헤더 위조 | 정확한 `TRUSTED_PROXY_IP`에서 온 `X-Real-IP`만 신뢰, 나머지는 실제 연결 IP 사용 |
| 프록시 설정 누락으로 정상 사용자 전체가 한도 공유 | 운영 설정에서 프록시 IP 필수화, IP 덮어쓰기와 비공개 백엔드 포트 안내 추가 |
| 느슨한 인증 응답 해석 | 토스 검증의 `success`가 boolean `true`인 경우만 인증 |
| 토스 CDN에서 받은 HTML의 보안 정책 누락 | 최종 HTML에 CSP 포함, 외부 스크립트·임의 API 연결 차단을 브라우저에서 확인 |
| 운영 설정 오류·공개 변수로 비밀키 유입 | HTTPS origin·앱 이름·저장 경로·프록시·모델·비용 한도 검증, 허용하지 않은 `VITE_` 변수로 빌드 시도하면 실패 |
| 운영 컨테이너가 개발용 인증 모드로 실행 | `NODE_ENV=production`에서 `APP_PLATFORM=toss` 필수 |
| 응답 대기 중 토스 뒤로가기 무반응 | 대기 중 종료 선택 제공, SDK 모의 이벤트로 확인 |
| 토스 웹뷰 확대 제스처 | 토스 화면만 제한, 일반 웹의 확대 기능 유지 |
| 인증서 아카이브 포함 위험 | 기존 PEM·KEY·P12 제외에 PFX 추가, Git·Docker 빌드 컨텍스트 제외 규칙 보완 |

## 검증 결과

- 자동 테스트 66개 통과, 이번 보안 테스트 8개 포함
- 문법 검사 통과, 평가 사례 형식 검증 30개 통과
- 의존성 `npm audit`: 당시 알려진 취약점 0건
- 현재 파일 75개·빌드 파일 5개·Git 이력 blob 247개 검사에서 사용 중인 API/저장 키와 OpenAI 키·개인키 패턴 미발견
- 사용자 소유권 분리·암호화 저장·기록 삭제·잘못된 암호화 키 차단·사용 한도 보존은 기존 회귀 테스트에서 재확인
- 시험 `.ait` 빌드 통과, `https://api.example.invalid`를 사용하므로 실제 제출용으로 사용할 수 없음
- 토스용 실제 앱 번들과 어댑터에 SDK 호출만 모의 구현해 안전 영역·native 저장소·뒤로가기·홈·대기 중 종료 확인
- 320/375/768/1440px 가로 넘침·JavaScript 오류 없음
- 브라우저에서 인라인 스크립트 실행과 허용되지 않은 origin으로의 fetch 차단 확인
- 실제 도메인·운영자 정보·실기기 확인이 없는 상태에서 `preflight:toss` 실패 확인
- 추가 유료 AI·토스 인증 API 호출 없음

점검용 검색은 알려진 키 패턴과 현재 사용 키의 포함 여부 검사이며 모든 종류의 비밀정보 부재를 증명하지는 않음. 실제 DB 내용을 열거나 사용자 대화를 출력하지 않음. 비밀키 값은 결과에 포함하지 않음

## 출시 전 필요한 작업

1. 토스 콘솔에서 앱 이름 확정, mTLS 인증서·개인키 발급
2. HTTPS API 도메인과 영구 디스크가 있는 단일 서버 준비, TLS 프록시 연결 IP·실제 클라이언트 IP 전달 검증
3. 운영자·고객지원 이메일·개인정보 처리방침·국외 처리 안내 확정
4. 운영 환경값으로 재빌드하고 `npm run preflight:toss` 실행
5. 토스 Android/iOS 실기기에서 실제 식별키·종료 후 복원·뒤로가기·키보드·안전 영역·느린 네트워크·신고·삭제 확인
6. 콘솔 소개·아이콘·스크린샷 등록 후 심사 신청

`PRIVACY_REVIEWED`, `TOSS_DEVICE_TESTED`는 해당 작업 완료 후에만 `true`로 변경. 실제 인증서와 키는 서버 비밀 설정에 보관하며 Git·채팅·클라이언트 빌드에 넣지 않음

## 점검 한계와 운영 조건

- 실제 mTLS 연결, 토스 WebView 기기 동작, 외부 배포 인프라 검증은 미완료
- Docker 실행 도구가 없어 컨테이너 실행 검증은 미완료
- 인증 검증 제한·동시 AI 제한은 서버 한 인스턴스 기준, 인증 캐시는 재시작 시 초기화
- 일일 AI 횟수와 누적 추정 예산은 영구 저장소 유지가 전제, 한도는 기본 30회/일·6회/분 구간·동시 3건·누적 $3
- IP를 공유하는 사용자는 신규 인증 제한도 공유, 분산 공격 방어는 운영 프록시의 연결·속도 제한으로 보완 필요
- 이 앱 밖에서 같은 OpenAI 키로 사용하는 비용은 앱 예산 원장으로 차단할 수 없음
- AI 입력·출력 검사와 신고·운영 중지 기능을 확인했으며 모든 위험한 답변 차단이나 답변 품질을 보장하는 검사는 아님
