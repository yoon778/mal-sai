# 말사이 웹 서버 준비

웹 공개를 위한 코드와 Render 설정을 준비했습니다. 실제 서버 생성·결제·배포는 아직 진행하지 않았습니다. 토스용 인증과 빌드는 그대로 지원합니다.

## 구성과 비용

- Render 싱가포르의 Node 24.18.0 서버 1개, SQLite와 예산 파일을 위한 영구 디스크 1GB
- 2026-09-10 기준 서버 $7/월 + 디스크 $0.25/월, 기본 $7.25/월입니다. AI·세금·초과 트래픽 비용은 별도입니다. 워크스페이스는 무료 Hobby로 시작할 수 있습니다. [공식 요금](https://render.com/pricing)
- 별도 도메인 구매 없이 Render가 제공하는 `*.onrender.com` 주소와 HTTPS를 사용합니다. [웹서비스 안내](https://render.com/docs/web-services)
- `render.yaml`에 서버 설정을 저장했습니다. 런타임 의존성이 Node 기본 모듈뿐이라 별도 패키지 설치나 프런트 빌드 없이 문법 검사·테스트·평가 사례 검증 후 실행합니다.
- 최초 배포는 `AI_ENABLED=false`인 체험 모드입니다. 서버 요금은 발생하지만 이 모드에서 OpenAI를 호출하지 않습니다.

## 처음 서버 만들기

1. [Render 대시보드](https://dashboard.render.com/)에 GitHub 계정으로 로그인하고 `yoon778/mal-sai` 저장소 접근을 연결합니다.
2. **New → Blueprint**에서 이 저장소의 `main` 브랜치와 루트 `render.yaml`을 선택합니다. [Blueprint 생성 안내](https://render.com/docs/infrastructure-as-code)
3. 서비스 1개, 싱가포르, `0.5c-512mb`, 디스크 1GB, 기본 월 $7.25인 구성을 확인합니다. 적용 버튼을 누르면 유료 리소스가 생성됩니다.
4. 필수 비밀값 `STORAGE_KEY`에는 로컬 `.env.web`에 생성한 64자리 hex 값만 입력합니다. 파일이 없다면 아래 명령으로 만듭니다. 키를 채팅이나 Git에 올리지 않습니다.

   ```sh
   npm run setup:web
   ```

5. 검토 후 Blueprint를 적용합니다. 정상 기동하면 서비스의 Render 주소를 엽니다. `APP_PLATFORM=web`, `/var/data` 영구 저장, HTTPS 주소 인식은 미리 구성되어 있습니다.
6. `/healthz`가 `{"status":"ok"}`를 반환하는지, 두 브라우저의 기록이 섞이지 않는지, 연습 후 새로고침과 서버 재배포 뒤에 기록이 유지되는지 확인합니다. 실제 볼륨 권한·프록시 헤더·HTTPS 쿠키는 이 단계에서 확인해야 합니다.

## 실제 AI 서비스 열기

1. 운영자·고객지원 이메일·개인정보 처리방침·국외 처리 안내를 확정하고 `public/privacy.html`과 앱의 데이터 안내에 반영합니다. 웹 세션은 가입 없는 브라우저별 기록이며 계정 간 동기화는 제공하지 않습니다.
2. Render **Environment**에서 `OPENAI_API_KEY`, `AI_ENABLED=true`, `SUPPORT_EMAIL`, 검토를 마친 뒤 `PRIVACY_REVIEWED=true`를 등록합니다.
3. Render Shell에서 `npm run preflight:web`를 실행합니다. 로컬에서 검사하려면 `.env.web`에 실제 `API_PUBLIC_ORIGIN`과 프록시 설정이 필요합니다. Render에서는 플랫폼이 주는 HTTPS 주소를 자동 사용합니다.
4. 설정 반영 뒤 새 연습에서 소량의 실제 답장·평가를 확인합니다. 이전 체험 연습은 계속 체험 모드로 유지됩니다.
5. 운영 중 추가 코드 배포는 테스트 후 수동으로 진행합니다. 현재 자동 배포는 꺼져 있습니다. Blueprint에 선언한 `AI_ENABLED` 같은 값을 변경한 뒤 다시 동기화할 때는 저장소 설정도 맞춰야 합니다.

## 적용한 보호 장치

- 임의로 만든 Bearer 값으로 웹 사용자 행세를 할 수 없습니다. 서버 서명과 만료 시간을 검증하는 `Secure`, `HttpOnly`, `SameSite=Strict` 쿠키를 사용합니다.
- 다른 출처의 변경 요청을 차단합니다. Render 환경에서만 플랫폼이 덮어쓰는 `CF-Connecting-IP`를 신뢰합니다. 일반 서버에서는 정확한 TLS 프록시 IP와 덮어쓴 `X-Real-IP`가 필요합니다. [Render 헤더 안내](https://render.com/articles/host-pocketbase-on-render)
- AI 한도는 기본 브라우저별·네트워크별 하루 30회, 분 구간당 6회, 서버 동시 3건입니다. 쿠키 재발급이나 기록 삭제로 네트워크 한도가 초기화되지 않습니다. 같은 와이파이·공유망은 한도를 공유할 수 있습니다.
- 세션 신규 발급은 IP당 시간 구간 10개·서버 전체 100개, API 요청은 IP당 분 구간 120개·전체 1200개로 제한합니다. 이 접속 제한은 메모리 기준이며 재시작 시 초기화됩니다. AI 이용 횟수는 SQLite에 보존됩니다.
- 모든 사용자가 공유하는 AI 누적 추정 예산은 $3입니다. 매일 자동 초기화되지 않으며 Render 서버 비용이나 다른 프로그램의 API 사용료를 포함하지 않습니다.
- 쿠키를 지우거나 만료되면 이전 기록 접근이 끊깁니다. 네트워크가 바뀌어도 같은 유효 쿠키는 기록을 유지합니다. 로그인·계정 복구가 필요한 규모가 되면 별도 계정 인증이 필요합니다.

## 재배포와 운영

- `/var/data`와 `STORAGE_KEY`를 유지합니다. 재배포할 때 데이터 디스크나 키를 새로 만들면 기록·예산 보존이 깨집니다. 키는 별도 보안 저장소에도 보관합니다.
- 디스크를 쓰는 Render 서비스는 기존 인스턴스를 먼저 종료하므로 재배포 중 중단이 있습니다. 여러 인스턴스로 늘리지 않습니다. [영구 디스크 제한](https://render.com/docs/disks)
- 종료 신호를 받으면 새 연결을 중단하고 최대 85초 동안 진행 요청을 마칩니다. Render 종료 대기는 90초입니다. 이미 처리 중인 요청을 강제 종료하면 다시 접속해 처리 결과를 확인합니다.
- 복원용 백업은 쓰기 요청이 없는 상태에서 SQLite와 `budget.json`을 함께 보존합니다. 임의로 과거 예산 파일만 복구하면 비용 상한을 되돌릴 수 있으므로 복원 시 사용량을 함께 확인합니다.
- 긴급 AI 중지는 Render Shell의 `npm run ai:pause`, 신고 목록 확인은 `npm run reports:list`입니다. 대화 내용이 포함되는 `--details` 출력은 운영자만 취급합니다.
- Render의 청구 화면에서 사용량을 확인합니다. 이 앱의 $3 제한이 호스팅 요금을 제한하지는 않습니다.

## 2026-09-10 검증

- 비밀파일과 `node_modules`가 없는 Git 준비본을 별도 디렉터리로 복사하고 Render 환경변수를 모의 주입해 문법 검사·테스트 80개·평가 사례 30개를 통과했습니다.
- HTTPS 프록시를 모의한 브라우저에서 보안 쿠키·사용자 분리·답장·새로고침·서버 재시작 복원을 확인했습니다. 320/375/768/1440px에서 가로 넘침과 JavaScript 오류가 없었습니다.
- 기존 토스 패키지 빌드와 SDK 모의 브라우저 검증도 통과했습니다. 실제 AI·토스 인증 API를 호출하지 않았습니다.
- Standards 리뷰: 정규화 URL에 대한 접속 제한과 외부 링크 진입 문제를 수정하고 회귀 테스트를 추가했습니다. 최종 잔여 지적은 0건입니다.
- Spec 리뷰: 외부 링크 진입 문제 수정 후 최종 잔여 지적은 0건입니다.
- Render 설정 필드는 공식 문서와 대조했습니다. 실제 콘솔의 Blueprint 승인·서버 생성·프록시·HTTPS 연결 검증은 계정 연결 후 진행합니다.

실제 외부 서버·결제·운영자 정보는 사용자 계정 단계가 남아 있습니다. 로컬 검증 통과를 실제 Render 배포 성공으로 간주하지 않습니다.
