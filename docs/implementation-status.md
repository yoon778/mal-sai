# 첫 작동 버전

구현일: 2026-09-07. 프로젝트명은 **말사이**입니다.

## 범위

배경 대화 8개, 상황 5개, 성별·적극성·농담 설정, 5회 자유 답장, 차례당 최대 3개 말풍선, 이모지, 읽기·답장 가상 시간, 힌트, 종료 후 복기, 특정 차례 재시도와 이전 반응 비교를 연결했습니다. 준비된 배경 말풍선은 채점하지 않습니다.

첫 연락·연락처 교환·대화 재개는 사용자가 먼저 시작합니다. 약속 취소는 15시 약속 전인 10시에 시작합니다. 초안의 힌트·시간·종료 조건은 조정 가능합니다.

## AI 상태

체험 모드와 실제 AI 모드를 모두 실행 검증했습니다. 체험 반응은 간단한 규칙과 준비된 문장으로 제한되며, 점수를 만들어내지 않습니다.

OpenAI 연결 코드는 대화 상대·힌트·평가 역할을 분리합니다. 모델은 `gpt-4.1-mini-2025-04-14`, 표준 처리 요금과 구조화 출력을 사용합니다. 입력 메시지는 시스템 지시와 분리하고, 평가 근거 ID·점수 범위를 서버가 검증합니다. 이것만으로 프롬프트 공격이나 편향이 해결됐다는 뜻은 아닙니다.

공식 자료 확인: [모델·요금](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [Chat Completions 요청 규격](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). 확인된 표준 텍스트 요금은 100만 토큰당 입력 $0.40, 캐시 입력 $0.10, 출력 $1.60이며 설정 변경 전 다시 확인해야 합니다.

비용은 요청 전 보수적으로 선예약하며 실패해도 예약액을 환불하지 않습니다. 반환된 실제 토큰 사용량의 추정 비용은 별도 로그에 기록합니다. 테스트에서는 가짜 API 응답만 사용했으며 유료 호출은 없었습니다.

## 검증 및 리뷰

- 자동 검증: 대화 전체 흐름, 입력·호스트 검증, 가상 시간, 중복 요청, 실패 시 상태 보존, 근거 기반 점수 집계, 예산 유지·중단, 구조화 API 요청, 첫 발화·성향 단서
- 브라우저: 5회 대화 종료, 힌트·이모지·나눠쓰기, 읽기 지연, 특정 답장 재시도, 이전 반응 비교, 390px 가로 넘침 없음, 입력 초점 복원, 콘솔 오류 없음
- Standards 리뷰: 통신 오류를 만료로 오인하는 복구 흐름과 재렌더링 시 키보드 초점 유실을 수정했습니다.
- Spec 리뷰: 먼저 연락하는 상황의 시작 방식, 성향별 배경 단서, 약속 취소 시각을 수정했습니다.

Git 기준점이 없는 최초 신규 파일 대상으로 두 리뷰를 수행했습니다. 기존 커밋과 비교한 PR 리뷰는 아닙니다.

## 다음 검증

실제 API 연결·자연스러움·동일 기록 평가 일관성·성별 변경에 따른 편향·사람의 피드백과 비교가 남아 있습니다. 유튜브 원문 수집, 학습 데이터 구축이나 모델 학습은 완료하지 않았습니다. 현재 평가는 연구에서 확정된 객관적 척도가 아니라 설계 초안입니다.

해커톤 제출용 공개 배포는 아직 하지 않았습니다. 로그인·공유·영구 대화 저장도 이번 버전에 포함하지 않습니다.

## 2026-09-07 다음 단계 진행

[해커톤 실행 로드맵](hackathon-roadmap.md)을 추가했습니다. 1단계로 5개 상황에 강한·약한·판단이 갈리는 창작 답장 2개씩, 총 30개를 `eval/cases.json`에 기록했습니다. 각 사례의 기대 행동 범위와 조사 문서의 출처 ID 연결을 `npm run eval:validate`로 검사합니다.

실제 AI 평가 실행 도구도 추가했습니다. `.env` 설정 후 `npm run eval:ai -- --limit 3`으로 세 사례부터 실행하며, 결과와 비용 기록은 `.data/`에 남습니다. API 키가 없어 실제 호출은 아직 실행하지 않았습니다.

대표 상황 3개를 실제로 완주하는 `npm run smoke:ai -- --limit 1` 도구도 준비했습니다. 각 판에서 상대 답장 5회, 힌트 1회, 평가 1회의 구조와 사용량 기록을 확인하고 응답 시간·토큰·추정 비용·결과를 `.data/smoke-live-*.json`에 저장합니다.

2026-09-07 실제 AI 3판을 완주했습니다. 소개팅 후 연락은 91점·13.6초·$0.005282, 애프터 제안은 95점·11.9초·$0.005445, 약속 취소는 89점·12.2초·$0.005408이었고 합계 추정 비용은 $0.016135였습니다. 첫 실행에서 찾은 평가 스키마 누락을 수정해 피드백을 최대 2개로, 근거를 해당 판의 실제 사용자 답장 ID로 제한했습니다.
