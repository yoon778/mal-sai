## 범위

배경 대화 8개, 상황 5개, 성별·적극성·농담 설정, 5회 자유 답장, 차례당 최대 3개 말풍선, 이모지, 읽기·답장 가상 시간, 힌트, 종료 후 복기, 특정 차례 재시도와 이전 반응 비교를 연결했습니다. 준비된 배경 말풍선은 채점하지 않습니다.

첫 연락·연락처 교환·대화 재개는 사용자가 먼저 시작합니다. 약속 취소는 15시 약속 전인 10시에 시작합니다. 초안의 힌트·시간·종료 조건은 조정 가능합니다.

## AI 상태

체험 모드와 실제 AI 모드를 모두 실행 검증했습니다. 체험 반응은 간단한 규칙과 준비된 문장으로 제한되며, 점수를 만들어내지 않습니다.

OpenAI 연결 코드는 대화 상대·힌트·평가 역할을 분리합니다. 초기 모델은 `gpt-4.1-mini-2025-04-14`였고 현재 대화 상대는 `gpt-5.4-mini-2026-03-17`로 변경했습니다. 표준 처리 요금과 구조화 출력을 사용하며 평가 근거 ID·점수 범위를 서버가 검증합니다. 이것만으로 프롬프트 공격이나 편향이 해결됐다는 뜻은 아닙니다.

공식 자료 확인: [모델·요금](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [Chat Completions 요청 규격](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). 확인된 표준 텍스트 요금은 100만 토큰당 입력 $0.40, 캐시 입력 $0.10, 출력 $1.60이며 설정 변경 전 다시 확인해야 합니다.

비용은 요청 전 보수적으로 선예약하며 실패해도 예약액을 환불하지 않습니다. 반환된 실제 토큰 사용량의 추정 비용은 별도 로그에 기록합니다. 테스트에서는 가짜 API 응답만 사용했으며 유료 호출은 없었습니다.

## 다음 검증

채팅의 문장 온점을 제거하며 숫자의 소수점과 URL, 사용자가 직접 작성한 문장은 보존합니다. 상호성 항목을 `답하고 이어가기`로 표시하고 평가자에게 직전 상대 발화와 사용자 답장을 묶어 전달합니다. 질문에 답하지 않은 되묻기와 답한 뒤 이어간 행동을 구분하며, 약속 확정과 자연스러운 마무리에 추가 질문을 강요하지 않습니다.

초기 관심을 랜덤·알아가는 중·관심이 낮은 상황으로 선택할 수 있습니다. 랜덤에서 낮은 관심은 30%인 제품 설정이며 현실의 비율을 뜻하지 않습니다. 상대 응답이 가상 30분 이상 걸리면 기다림 상태로 들어가고 30분·2시간씩 시간을 넘길 수 있습니다. 도착 전 본문과 미래 읽음 시각은 API에도 노출하지 않습니다. 기다리기는 추가 AI 요청을 만들지 않습니다. 다섯 번째 답장과 재시도에도 같은 대기 처리를 적용합니다. 영구 무응답은 이번 범위에 포함하지 않습니다.

실제 사용자 3~5명의 현실감·유용성 평가와 공개 환경의 모바일 완주 검증이 남아 있습니다. 유튜브 원문 수집, 학습 데이터 구축이나 모델 학습은 진행하지 않았습니다. 현재 평가는 연구에서 확정된 객관적 척도가 아니라 설계 초안입니다.

해커톤 제출용 공개 배포는 아직 하지 않았습니다. 로그인·공유·영구 대화 저장도 이번 버전에 포함하지 않습니다.

사용자 검증을 위해 결과 화면에 1분 설문을 추가했습니다. 현실감·피드백 유용성·재시도 의향과 진행 막힘, 짧은 의견만 `.data/feedback.jsonl`에 저장하며 대화 내용은 포함하지 않습니다. `npm run feedback:summary -- --participants 5`로 결과를 집계합니다. 실제 참여자 3~5명의 검증은 아직 필요합니다.

대화 중 `말이 끊겼어요 · 주제 찾기`를 누르면 현재 기록에서 꺼낼 소재, 연결 문장, 답을 받은 뒤 이어갈 방식과 피할 행동을 확인할 수 있습니다. 여성 서윤은 부드러운 해요체, 남성 도윤은 담백한 해요체라는 인물별 규칙을 사용하며 적극성·농담 설정을 함께 반영합니다. 성별 전체를 일반화하는 말투는 만들지 않습니다.

AI 답장은 반응·내용 답변·자기 이야기·되묻기의 기능 경계에서 1~3개 말풍선으로 나눕니다. 짧은 단어도 독립적인 반응일 때 사용할 수 있지만 조사·서술어·글자 수 기준의 기계적인 분절은 피합니다. 연속 말풍선은 화면에서 하나의 말차례로 묶어 이름은 처음에, 시간은 마지막에만 표시합니다. 현실감 검사에는 평균 말풍선 수, 복수·세 개·짧은 말풍선 비율과 기계적 분절 검사를 추가했습니다.

수정 후 실제 AI 10판·50차례를 다시 실행한 결과 평균 1.40개, 복수 말풍선 40%, 역할 혼동·사실 모순·말투·분절 문제 0건, 동일 마무리 0%로 통과했습니다. 390px 모바일 화면에서도 첫 풍선에 이름, 마지막 풍선에 시간만 표시되고 가로 넘침이 없음을 확인했습니다.

말투 설정에 랜덤·존댓말·반말을 추가했습니다. 랜덤은 두 말높임 중 하나를 고르며, 반말은 각 상황의 이전 대화와 첫 메시지부터 자연스러운 반말 자료를 사용합니다. 성별과 말높임은 독립적으로 조합되고 AI·체험 답장·주제 연결 예시가 선택한 말높임을 유지합니다.

## 2026-09-07 다음 단계 진행

[해커톤 실행 로드맵](hackathon-roadmap.md)을 추가했습니다. 1단계로 5개 상황에 강한·약한·판단이 갈리는 창작 답장 2개씩, 총 30개를 `eval/cases.json`에 기록했습니다. 각 사례의 기대 행동 범위와 조사 문서의 출처 ID 연결을 `npm run eval:validate`로 검사합니다.

대표 상황 3개를 실제로 완주하는 `npm run smoke:ai -- --limit 1` 도구도 준비했습니다. 각 판에서 상대 답장 5회, 힌트 1회, 평가 1회의 구조와 사용량 기록을 확인하고 응답 시간·토큰·추정 비용·결과를 `.data/smoke-live-*.json`에 저장합니다.
