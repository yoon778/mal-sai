- 개선: 전송 결과가 불확실하면 현재 기록을 다시 조회하여 화면과 초안을 동기화합니다. 요청 ID나 예상 차례를 함께 검증하여 재전송이 중복 처리되지 않도록 합니다. 클라이언트 요청 제한 시간도 필요합니다.

## 추가하면 좋은 기능

### 1. “여기서 잘 마무리하기”

현재는 상대가 아파서 “오늘은 푹 쉬세요, 답장 안 하셔도 돼요”라고 자연스럽게 끝내도 5회 답장을 채워야 복기할 수 있습니다. 이는 원래 5회 사양에는 맞지만 기다림·마무리를 가르치는 목표와 충돌합니다.

조기 마무리 선택을 제공하고 관찰된 항목만 평가합니다. 짧은 대화는 관찰 범위가 적다고 표시하며 낮은 점수로 처리하지 않습니다.

### 2. “왜 어색했나요?” 품질 제보

기존 위험 답장 신고와 구분하여 역할 혼동·시간 모순·말투 부자연스러움·납득하기 어려운 평가를 선택하게 합니다. 사용자 동의를 받은 사례에 모델·프롬프트 버전과 재현 가능한 맥락을 연결하면 실제 불편을 개선 자료로 사용할 수 있습니다.

### 3. 복기 뒤 새로운 상황에서 한 문장 복습

현재의 같은 장면 재시도에 더해, 방금 놓친 행동을 다른 상황에서 한 번 적용해 보도록 합니다. 예를 들어 “질문에 답하고 내 경험 한 조각 더하기”를 배웠다면 다른 질문에 새 답장을 작성하게 합니다. 총점 상승보다는 바뀐 행동 한 가지를 설명합니다.
